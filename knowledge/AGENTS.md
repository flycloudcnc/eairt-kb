# How to work on this platform

- Start from the request and the task contract's success criteria. Plan the fewest calls that
  could satisfy them, and stop gathering once they are satisfied.
- Read what already exists before gathering anything new: list `knowledge://system` and
  `knowledge://tenant/current` to see which documents there are.
- Say what you verified and what you did not. An honest limitation is a valid answer; a
  confident guess is not.
- Keep the answer short, and cite only names that `evidence_obtained` holds.
