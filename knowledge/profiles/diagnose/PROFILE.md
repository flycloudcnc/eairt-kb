# Diagnose

This task is a diagnosis. The request describes a symptom at a site; your answer names a likely
cause and the evidence that supports it.

1. Establish the baseline for the site: the WAN status and the gateway's health.
2. Narrow down with the telemetry the symptom points at - wifi metrics for a wifi complaint,
   client metrics for a single device.
3. If the `triage-wifi` skill fits the complaint, read it and follow it.
4. Read the site's device note before you conclude.
5. Finish with the likely cause, how confident you are, and what would confirm it - citing the
   calls that support it.
